01

The Wordmark

One word, two weights. UPP in Inter Black asserts control; SOLUT in Inter Light carries momentum. The two primary colorways are Crimson on Platinum and Platinum on Crimson — everything else is a supporting pairing.

Primary · Crimson on Platinum
Primary · Platinum on Crimson
Weight split

UPP = Inter 900 · SOLUT = Inter 300. Never equalize the weights.

Subline lock

Tagline width = wordmark width, always. It spans edge-to-edge and never overhangs.

Letter spacing

Tracking is opened for an engineered read. Set via width-lock, not manual kerning.

Casing

Wordmark and subline are always all-caps. No lowercase, no title case.

06

Sub-brand Architecture

Modules use the stacked lockup: UPPSOLUT fixed on top, the module name set larger below, sharing the same left edge. The engine stays present; the module carries the volume — and the footprint barely changes from one module to the next.

Construction rules

Anchor
UPPSOLUT wordmark defines the width (1W) and the left edge for the whole lockup.
Ratio
Module cap-height ≈ 2.4× the UPPSOLUT cap-height. Module weight = Inter 900.
Gap
Vertical space between UPPSOLUT baseline and module cap ≈ 0.5× module cap-height.
Color
Module name = Crimson on light / Platinum on dark. UPPSOLUT = Obsidian on light / Platinum on dark.
Width cap
Module must not exceed 1W. If it would, reduce its size until it fits — the box never widens.
Casing
Module name always all-caps, no subline. The stacked mark replaces the tagline.

08

Usage Rules

The mark stays disciplined. Protect the weight split, the width lock, and the palette.

✓ Do
  • Keep UPP black and SOLUT light — always.
  • Lead with Platinum ⇄ Crimson; lock the subline to the wordmark width.
  • Stack sub-brands: UPPSOLUT anchored, module at 2.4×.
  • Give the mark at least 1U of clearspace.
  • Reduce to the standalone U at small sizes.
✕ Don't
  • Don't equalize the weights or swap them.
  • Don't stretch, skew, outline, or add shadows.
  • Don't let a module name grow wider than the UPPSOLUT anchor.
  • Don't recolor into off-brand hues or gradients.
  • Don't substitute a different typeface for Inter.
